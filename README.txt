PeerhiPro — Family Tree (شجرہ)
================================
Files:
  index.html  — page structure
  style.css   — design
  app.js      — app logic

How to run:
  1. Unzip this folder
  2. Open index.html in Chrome / Edge / Firefox
  3. Or host the whole folder on GitHub Pages / Netlify

GitHub Pages:
  Upload all three files to repo root (index.html must be at root)
  Settings → Pages → Deploy from branch main / root

Data stays in browser LocalStorage.
Use More → Export JSON for backup.
